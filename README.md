# Todo List

A clean, responsive, and lightweight Todo List web application built with Vanilla HTML, CSS, and JavaScript.

## Features

- **Add Tasks**: Quickly add new tasks to your list.
- **Mark Complete**: Check off tasks with a strikethrough effect.
- **Edit Tasks**: Double-click any task text to edit it inline.
- **Delete Tasks**: Remove unwanted or completed tasks with a single click.
- **Persistent Storage**: Automatically saves all tasks in the browser's `localStorage` so your list persists across sessions.
- **Responsive Design**: Clean UI optimized for both desktop and mobile screens.

## Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**

## Getting Started

Simply open `index.html` in your web browser, or use a local dev server such as Live Server in VS Code.
